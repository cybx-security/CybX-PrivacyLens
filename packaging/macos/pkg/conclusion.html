PrivacyLens is installed

To use it: open the Applications folder and double-click PrivacyLens. It opens in your web browser — choose the folders to check and click Scan. Every scan is saved automatically.

To check that it is working, open Terminal and run privacylens status

To read scanned documents and photos, PrivacyLens uses the free Tesseract and Poppler tools. If they are not on this Mac yet: brew install tesseract poppler

To remove PrivacyLens, run sudo privacylens uninstall in Terminal.
